# دومنو الصحبة v6.2 — Game Feel & PWA

هذه النسخة مبنية على v5 وتحافظ على Firebase الحالي والشات الكتابي والصوتي.

## الجديد
- ترتيب اليد: ذكي / الدبلات أولًا / حسب الرقم / يدوي بالسحب / بدون ترتيب.
- إبراز طرفي سلسلة الدومينو أثناء دورك.
- Highlight + تركيز تلقائي على آخر حجر تم لعبه.
- صوت مزدوج للدبل + اهتزاز خفيف على الأجهزة التي تدعم Vibration.
- شاشة نتيجة بين الجولات مع النتيجة والتقدم نحو 51/101/151/201.
- ملخص نهائي: عدد الجولات، مرات القفل، أكبر جولة.
- سجل آخر 10 مباريات على الجهاز فقط باستخدام localStorage.
- قواعد إضافية قبل إنشاء الغرفة:
  - البداية: أعلى دبل / منشئ الغرفة / عشوائي.
  - حساب القفل: فرق الأحجار / مجموع أحجار الخاسر.
- مؤشر إعادة الاتصال، واستمرار المباراة عند عودة الشبكة.
- تنظيف الغرفة المحفوظة القديمة بعد 7 أيام عند فتحها من نفس الجهاز/الحساب المجهول.
- PWA حقيقية: Service Worker + أيقونات 192/512 + زر تثبيت عندما يدعم المتصفح ذلك.
- ثيمان للطاولة: أخضر كلاسيكي وخشبي داكن.
- نفس Footer: تصميم وبرمجة محمد حسين — iegy.net.

## الرفع
استبدل محتويات الريبو الحالية بكل محتويات ZIP، بما في ذلك:
- `service-worker.js`
- مجلد `icons/`
- مجلد `assets/`

لا تحتاج لتغيير `firebase-config.js` أو Realtime Database Rules الحالية.

## ملاحظة التنظيف التلقائي
لأن المشروع GitHub Pages + Firebase بدون Backend أو Cron، لا يمكن إجراء حذف عالمي دوري لكل الغرف. v6 تنظف الغرفة القديمة التي تخص الجهاز الحالي عندما يرجع المستخدم إليها، وهو حل آمن يحافظ على التشغيل المجاني 100%.
